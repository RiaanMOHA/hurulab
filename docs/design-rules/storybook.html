Spacing

The scale

Ten steps, each a multiplier of the body size, from a quarter of it to eight times it. Every value is rem on the root clamp, so space breathes with the text by the same 17-to-20 proportion at every width. Only steps with a job exist: a spare step gets used decoratively.

The three kinds of space

KindWhat it isWhere it sits
InsetThe space inside a surfaceCard s-5. Panel and input s-4. A control's vertical inset s-2
GapThe space between siblingsBento and card grids s-5. Form fields s-4 between, s-2 inside. Icon to label s-3. Paragraphs s-4
RhythmThe space between sectionss-9 vertical at 360, s-10 from 768 up. A heading takes more space above it (s-7) than below (s-5), so it belongs to what follows

The rules

RuleWhy
Only stepsAn off-scale value is the spacing equivalent of a hex color
Closer means relatedProximity is hierarchy. A reader should be able to parse the page's structure from spacing alone
The parent owns the gapA component carries no outer margin. Whatever lays components out sets the space between them, which is what lets one component sit in different contexts without exceptions
Space separates, decoration does notBefore reaching for a second hairline, a box or a background, take one more step of space
No pxThe one exception is the hairline

1440 is where you design. 360 is where you prove it. A layout that only holds at 1440 is not finished. Body text starts at 17px, Apple's own body default, and grows to 20px at 1560, fluid between and clamped at both ends. Every other size in the system derives from that root, which is why nothing here is set in pixels.

Top left radius at true size, the C2 curve on everything. Apple's continuous curve, capsules included: the curve blends into the straight edge with no visible start point. In code it is one line beside the radius, corner-shape: squircle, and it degrades cleanly, so browsers that cannot draw it yet show the plain radius and nothing breaks. The optional trailing icon

Added only when the icon says something the label cannot: a direction, a destination, an external link. It trails, never leads, and takes the label's own color. An icon added to make a button look finished fails review.

The label wraps, it never truncates

Carbon's rule over Atlassian's. The copy here is written rather than generated, so a cut sentence only ever reads as broken.

Always

Wraps to a second line.

Never

Truncated. The action is now unreadable.

Focus is a border, never a ring

Never two lines at once. The general focus ring sits outside the element, so on a button that already has a border it draws a second edge around the first. Instead the button's own border thickens to 2px and darkens one step, and the padding loses a pixel each side so the button does not change size. button-ghost has no border to thicken, so it draws no focus state. The ring still applies to inputs, checkboxes and links.

Always

One line. The border thickens and darkens.

Never

A ring outside a border. Two edges at once.

When not to use a button

NeverWhy
For navigationA thing that takes you somewhere is a link. Using the wrong one makes the experience harder to use
Two primaries in one viewIf two actions are equally important, one of them is not
Disabled, where validation would doA disabled button leaves the tab order and receives no hover, focus or click, so it is invisible to some people. Say what is missing instead
A tooltip on a disabled buttonIt cannot be reached to reveal it
A noun alone as the labelA button names its action. "Book a Call", never "Call"

The hover and pressed specimens are drawn with a state class so they can be seen at rest. A real button uses :hover and :active, which carry the same values.

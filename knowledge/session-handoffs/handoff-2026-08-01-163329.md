## Problems encountered and how they were solved

- **Sub-agent output truncation.** Asking sub-agents to return large (70–110KB) compiled documents as their final chat message caused the harness to silently redirect the content into a `<persisted-output>` pointer to a file on a machine path outside any mounted directory, and that file's structure (one giant JSON-escaped string on a single line) exceeds the Read tool's per-call token cap with no way to paginate around it. Fix: re-ran the same 4 research tasks, this time instructing agents to use the Write tool to save their compiled markdown directly into the Cowork outputs directory (a path Read/Write can access normally), and to reply with only a short confirmation line. This worked cleanly every time afterward.
- **notion-fetch parameter name.** First call used `url` as the parameter key (matching casual naming from the tool description's prose) and got a validation error; the actual required key is `id` (the tool accepts either a raw ID or a full URL as the value of `id`).
- **User confusion from silent long-running work.** Because the folder-reading and sub-agent phase produced no visible Notion changes for several tool-call rounds, Riaan sent two frustrated interruptions. Both were handled by immediately pausing to give a short, plain-status update (no jargon, explained scratch files vs. final destination) before resuming. **Lesson for future sessions doing large multi-phase work: proactively narrate phase transitions in short plain sentences, don't wait for the user to ask.**
- **Handoff written to a dot-directory.** The `handff` skill's own instructions say to write to `.handoffs/`, but this project's actual convention (per Riaan, stated directly and angrily) is to never use dot-prefixed handoff directories, because they can't be read reliably in a later session. **Fix and standing rule: always write handoff files to `handoffs/` (no leading dot) in this project, regardless of what any skill's default instructions say.** This overrides the `handff` skill's literal instructions for this project going forward.
